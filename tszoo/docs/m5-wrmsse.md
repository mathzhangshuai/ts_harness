# M5 WRMSSE 口径

当前结果见 [基线表](m5-zero-shot.md#当前结果)。旧实验分数已移除。

- 先将底层 q0.5 点预测与真实销量分别聚合，再计算误差；不将聚合后的点预测称为聚合分布的中位数。
- 共 12 层、42,840 条层级序列，每层权重为 1/12。
- 缩放使用 d_1 至 d_1913 的完整历史，从首个非零销量之后计算相邻差的平方均值；不只使用 512 天输入窗口。
- 权重使用 d_1886 至 d_1913 的实际销量乘对应周价格，层内按销售额归一化。
- 每条序列 `RMSSE = sqrt(mean((prediction - target)^2) / scale)`；WRMSSE 为各层销售额加权 RMSSE 的平均值。
- 零缩放、正销量缺失价格、标签或序列错位会报错，不静默跳过。

实现见 [score_m5_wrmsse.py](../utils/score_m5_wrmsse.py)。`baseline` 入口自动完成此评分，无需另跑命令。
