# tszoo 时序预测实验上下文

本项目研究零售需求预测，当前结果范围为 M5 仅目标变量零样本回测。实验协议、证据与运行方式见 [结果索引](docs/README.md) 和 [项目说明](README.md)。

## 术语

**目标变量（target）**：
待预测的销量序列；M5 底层序列对应一个商品与门店组合。

**静态特征**：
不随时间变化的类别或实数属性，对应 `feat_static_cat` 和 `feat_static_real`。

**未来已知动态特征**：
预测时能获得历史及预测区间取值的协变量，对应 `feat_dynamic_cat` 和 `feat_dynamic_real`；能否已知由业务信息边界决定。

**仅过去已知动态特征**：
只允许读取预测起点之前取值的协变量，对应 `past_feat_dynamic_cat` 和 `past_feat_dynamic_real`。

**仅目标变量零样本回测**：
只输入目标历史，使用预训练权重而不在 M5 上拟合参数。该称谓不证明预训练数据中不存在 M5。

**变量组**：
共同参与变量注意力的目标和协变量集合；当前 M5 基线每条商品门店序列各自成组，组间隔离。

**目标受限注意力（target_aware）**：
目标可以读取组内协变量，协变量状态不能读取目标；双向策略为 `bidirectional`。这里的“受限”指信息流方向，不代表自动保证协变量在业务上可知。

**回测窗口**：
当前基线以 d_1913 为历史终点，输入最近 512 天并预测 d_1914 至 d_1941 的 28 天。此窗口已用于探索，不能再称为未接触的最终测试集。

**点预测**：
当前基线取 q0.5，不裁剪、不舍入；聚合层点预测为底层点预测之和，不声称等于聚合分布的中位数。

**WAPE**：
全部序列和 28 天的绝对误差之和除以真实销量之和；是误差比例，不是准确率。

**M5 WRMSSE**：
12 层共 42,840 条层级序列的加权缩放平方根误差。缩放使用截至 d_1913 的完整历史，权重使用 d_1886 至 d_1913 的销售额；评分使用价格不等于模型输入使用价格。
